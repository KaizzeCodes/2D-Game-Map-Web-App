# Custom Project: 2D Map Builder & Notes Tool

A custom browser application designed to build maps for 2D games (such as *La‑Mulana*) and take notes.

This was created as a pet project to experiment with “vibe coding” using Microsoft Copilot.

I am an experienced developer, but not an experienced front‑end designer, so this project was a fun challenge.

**Disclaimer:**  
I did not review every line of code generated by AI.

## Description of Elements

**server.js**  
Backend support for the application, running Express.js.

**index.html**  
Frontend for the application, containing the canvas, UI, snapping logic, and notes panel.

**global.json**  
Stores the order of maps displayed in the top menu.

**Launch_App.bat**  
This will attempt to install Express.js if it's not already installed.
This will add more files/folders.
Once Express.js is installed running it will leave a command prompt window open this is your backend "server" for the application.
Open your browser (this was designed and tested using Chrome) and go to the url "http://localhost:3000/".
Keep in mind you must leave the command prompt open while using the application.

**Maps/**  
Dynamically managed folder that stores map data, including images, text, and canvas layout parameters.

## Feature Explanation

- The top menu allows the user to **Add Map**, generating a new map folder.  
  This was designed with *La‑Mulana* in mind, which contains many smaller interconnected maps.
  You can also right click a map to delete it, this removes the entire respective folder for that map.

- Each generated map appears in the top menu. Selecting a map loads its **canvas** and **notes section**.

- **Right‑clicking a map entry** allows deletion, which removes the entire folder.

- The canvas supports:
  - Drag‑and‑drop screenshots  
  - Automatic snapping  
  - Panning  
  - Zooming  

- **Right‑clicking an image** allows assigning a title (inspired by La‑Mulana’s room naming).

- Each map has its own **notes section** on the right side of the application.
